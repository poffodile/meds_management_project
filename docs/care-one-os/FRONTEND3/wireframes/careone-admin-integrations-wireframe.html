Terminology

Audit records, exports and the API always say subject_of_care, whatever the interface shows. That is what makes a children's home and a nursing home comparable in the same data model.

Configuration boundary

Locked

You may rename concepts, enable optional modules and define escalation routes. You may not switch these off:

  • ■ Identity checks before administration
  • ■ Outcome coding on every non-administration
  • ■ Audit capture on every clinical event
  • ■ Controlled-drug witnessing rules

Configuration flexes the product to the setting. It never weakens the core controls.

Permission model

  • Deny by default.
  • Scoped by organisation, site, team, person relationship and function.
  • Step-up authentication for high-risk actions.
  • The policy version and permission decision are recorded with the event.
  • Break-glass access is time-limited, justified, alerted and audited.
