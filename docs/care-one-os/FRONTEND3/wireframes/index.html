The design language

  • Manrope for headings, Inter for body and UI.
  • Radius 12–16px, eight-point spacing, elevation reserved for overlays.
  • Status carries a word, a shape and a tint — ● Due, ✓ Done, ▲ Late, ■ Risk, ◐ In progress. Never colour alone.
  • Hairline borders, no heavy shadows, no rainbow badges.
  • All of it scoped under .f3-root in one stylesheet.

How to review these

  1. Open each screen and resize the window from wide down to about 390px. The layout should go three-zone → list-detail → single column, and the navigation should go labelled sidebar → icon rail → bottom bar. Nothing should ever scroll sideways except the tables and the MAR grid, which scroll inside their own frames.
  2. Tab through with the keyboard. Every control should show a clear teal focus ring.
  3. Look for the annotated notes in green — each one explains a rule from the specification that the screen is enforcing, so you can check whether you agree with the interpretation.
  4. Say what is wrong. These are a starting position, not a proposal to be accepted or rejected whole.

All people, medicines, doses, sites and events are fictional. Nothing here is clinical advice or a compliance claim.
