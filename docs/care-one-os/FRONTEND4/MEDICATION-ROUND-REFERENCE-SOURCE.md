# Medication Round Reference Source

The source archive supplied by the owner is saved here:

`docs/care-one-os/FRONTEND4/care-one-os-medication-round-source-reference.zip`

Use it as the visual, layout, responsive behaviour and workflow reference for the Frontend4 medication round page.

Do not copy prototype clinical records, people, medicine names or staff names into the Laravel app. Frontend4 must use existing backend data where it exists and explicit placeholders such as `Not recorded` where the backend has no value.
