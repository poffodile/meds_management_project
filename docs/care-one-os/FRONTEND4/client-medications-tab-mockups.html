Client Profile - Medications Tab Mockups

Standalone UI directions for the medication area. These are not wired to Laravel and do not change live behavior. They are here so we can choose a direction before applying it to Frontend4.

Stress case shown: regular medicine, PRN medicine, inhaler, low stock, paused medicine, and enough items to test desktop and mobile spacing.
